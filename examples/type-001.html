Why the agent drifts like this

Agents pattern-match per component. A "modern hero" prompt pulls a display serif; a "clean form" prompt pulls an unsafe sans; a label near data pulls a mono. Each local choice reads plausibly. The screen as a whole reads like four unrelated products stacked on one page.

The repair

Declare the type system by role, not by taste: one reader family for paragraphs and headings, one interface family for controls and labels, mono for code. Weight, size and letter-spacing do everything else. Two families, applied on purpose, survives every screen.

Find it in your project

Paste your CSS into Guard Lite with a fonts = contract line — PPG-TYPE-001 flags every declared family that is not on the list.
