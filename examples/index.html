01 · The five sins

One habit per demo. One Guard rule per habit.

Each entry explains why the coding agent drifts that way, shows the repair, and links to the Guard rule that detects it in your own project.

PPG-COLOR-001

The rainbow button soup

Six accent colours on one screen. The fix: one accent, everything else earns attention with weight and size.

Live demo →

 PPG-TYPE-001

LCD typography

Three unrelated font families on one screen, headings italic by accident. The fix: two families, assigned by role.

Live demo →

 PPG-TYPE-002

The text wall

Thirteen-pixel body text crossing the whole container with no hierarchy. The fix: a 62-character measure and a small type scale.

Live demo →

 PPG-SPACE-001

The pixel crime scene

7px here, 23px there, icons kissing labels. The fix: one spacing scale, applied by structural role.

Live demo →

Border-radius chaos

A pill button beside a square badge beside a 22px card. The fix: one radius scale, consistent by component size.
