Why the agent drifts like this

Spacing has no protected token layer in most generated code, so the agent improvises: 7 instead of 8, 23 instead of 24, 3 instead of 4. Every improvisation is invisible alone. Together they destroy rhythm — and the screen reads as "cheap" before anyone can say why.

The repair

Declare one scale (4 / 8 / 16 / 24 / 48) and map spaces to roles: within-component space, between-component space, between-section space. Same-role spaces get the same value everywhere, at every viewport.

Find it in your project

Paste your CSS into Guard Lite with a spacing = contract line — PPG-SPACE-001 lists every literal margin, padding and gap outside the scale.
